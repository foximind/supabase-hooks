# 🧩 @foximind/supabase-hooks

**The ultimate React hook library for Supabase.**  
Build modern, scalable apps faster with ready-to-use, type-safe, and customizable hooks for Supabase Auth, Database, Storage, and Realtime.

---

## 🚀 Why @foximind/supabase-hooks?

- ✅ Fully typed with TypeScript
- ⚡ Built on top of Supabase JS SDK v2
- 🔄 Optional support for TanStack Query
- 🧩 Modular hooks for Auth, DB, Storage, and Realtime
- 🌍 Works with Next.js, Vite, CRA, etc.
- 💯 Clean API, excellent DX, and composable patterns
- 📦 Lightweight, no heavy dependencies

---

## 📦 Installation

```bash
npm install @foximind/supabase-hooks @supabase/supabase-js
# or
yarn add @foximind/supabase-hooks @supabase/supabase-js
```
